# PiyopiyoToonz

ブラウザだけで動く、2D アニメ向けの簡易コンポジターです。背景（静止画または動画）と透過 PNG のセル連番を**レイヤーとして自由な順番で重ね**、音声クリップと一緒にタイムラインで編集し、**編集結果を 1 本の MP4 として書き出せます**。背景をセルより手前に置けば BOOK になります。PC のほか、iPad の Safari でも使えるようにタッチ操作と画面レイアウトを合わせています。

## できること

- **背景 / BOOK レイヤー** … png / jpeg / webp / mp4 / webm など。何枚でも読み込めて、セルの奥にも手前にも置けます
- **セルレイヤー** … 透過 PNG 連番（ファイル名の数値順）。レイヤーごとに fps・不透明度・拡大・位置・合成モード
- **音声レイヤー** … wav / mp3 / m4a など
- **直接操作** … ステージの絵をドラッグして移動、角をつまむ / ピンチ / ホイールで拡大縮小
- **撮影処理** … レイヤーごとに トーンカーブ・カラー合成・光源・グロー・ぼかし
- **画面の畳み込み** … 細かい設定はすべて畳めます。**シンプル**に切り替えれば要るものだけの画面になります
- **重なり順** … リストの下にあるレイヤーほど手前。各レイヤーの「▲ 奥へ / ▼ 手前へ」で入れ替え
- **タイムライン編集** … 移動、トリム、分割、コピー / 切り取り / 貼り付け、複製、繰り返し、元に戻す
- **プレビュー** … 背景の fps とセルの fps は独立。プロジェクト fps でコマ送り。プレビューとタイムラインの境目はドラッグで高さを変えられます
- **書き出し** … 画面に見えている合成結果（背景 + セル + セルの撮影処理 + 音声）を、名前と保存先を決めて MP4 に書き出し
- **シーンの保存** … レイヤー構成・配置・撮影処理・タイムラインを JSON に保存。読み込めば同じ状態から続きを作れます

## 使い方

1. 背景を読み込む（またはステージへドロップ）。手前に重ねたい絵は **BOOK を読み込む** から
2. 「透過PNG連番を読み込む」でセルを追加する（セルの既定は 8fps）
3. 必要なら音声を追加する
4. 位置と大きさを決める（**直接操作**、または数値入力）
5. セルに **撮影処理** をかける
6. タイムラインでタイミングを合わせ、プレビューで確認する
7. 右上の **MP4書き出し** を押し、名前と保存先を決めて書き出す

作業の途中で **シーン** の「💾 シーンを保存（JSON）」を押しておくと、あとから同じ状態に戻せます。

クリップを削除して、そのレイヤーのクリップが全部無くなると、レイヤーごと消えます（元に戻すで復帰できます）。

素材が無い状態では書き出せません。書き出し中はプレビューが一時停止します。

## 画面を軽くする

設定が増えたので、出すものを絞れるようにしてあります。

- **枠を畳む** … 「ステージ」「配置・合成」「撮影処理」やその中の各工程は、見出しをタップで開閉します。開閉は覚えるので、次に開いたときも同じ形です
- **入切と開閉は別** … 撮影処理の各工程にある **◉ / ◯** は効果の入切です。畳んでも効果は生きたままなので、決まった設定は畳んでしまって構いません
- **シンプル表示** … 右上の **シンプル** を押すと、数値入力・配置・合成・ステージ設定・再生速度などを隠して、読み込み / 不透明度 / 直接操作 / 撮影処理のプリセット / 重なり順だけの画面になります。**くわしく** で元に戻ります

## 位置と大きさを直接いじる

プレビュー左上の **✥ 直接操作** を押すと、ステージの絵を直接動かせるようになります（レイヤーパネルの「✥ ステージで直接動かす」からでも入れます）。

| したいこと | 操作 |
| --- | --- |
| 動かすレイヤーを選ぶ | ステージのその絵を触る（一番手前が優先）／上のリストから選ぶ |
| 移動 | ドラッグ |
| 拡大縮小 | 角のハンドルをつまむ / 2本指のピンチ / ホイール |
| 元に戻す | **リセット**（拡大率 100%、位置 0,0）／ Ctrl+Z |

拡大は絵の中心を軸にするので、大きさを変えても位置はずれません。数値で詰めたいときは、これまで通りレイヤーパネルの拡大率 / X / Y が使えます。

## 撮影処理

レイヤーごとの **🎬 撮影処理** で、背景と別にセルだけを加工できます。処理は上から順にかかります。

| 工程 | できること |
| --- | --- |
| ① ぼかし | フォーカス送り、奥のセルのボケ |
| ② トーンカーブ | コントラスト、色かぶり。RGB 一括とチャンネル別 |
| ③ カラー合成 | 絵全体に一色を被せる。スクリーンで夕日、乗算で沈める |
| ④ 光源 | 点光源 / 平行光のグラデーション。乗算にすれば影（パラ）にもなる |
| ⑤ グロー | 明るいところだけをぼかして足し戻す。輪郭の外へ滲むので透過光に |

**夕方 / 夜 / 朝 / 逆光 / 回想** のプリセットから始めて、あとから各工程を詰めるのが楽です。

- 処理は素材の解像度で焼くので、プレビューと書き出しの絵が一致します
- セルは 1 コマずつ結果を溜めるので、2 周目からの再生は軽くなります
- グローとぼかしは Canvas のフィルタを使います。対応していない古いブラウザでは効きません（パネルにその旨が出ます）
- 背景動画に掛けると毎コマ焼き直すのでプレビューが重くなります（書き出しの絵は変わりません）

## シーンの保存と読み込み

サイドバーの **シーン** から、いま開いているシーンを JSON に書き出せます。

入るもの … レイヤーの構成と重なり順、配置（拡大率 / X / Y / 配置 / 合成モード）、不透明度、セルの fps、
撮影処理の設定（トーンカーブの制御点まで）、タイムラインのクリップ、ステージ設定、プロジェクト fps と音量、
そして **素材のファイル名**。

入らないもの … 絵と音そのもの。連番セルを丸ごと抱えると JSON が何百 MB にもなってしまうので、
素材はファイル名で覚えておき、読み込むときに選び直す形にしています。

読み込みは「📂 シーンを読み込む（JSON）」か、**ステージへ JSON をドロップ**。
素材を結び直す画面が出るので、そのシーンで使った素材（フォルダごとで構いません）をドロップするか、
「ファイルを選ぶ / フォルダを選ぶ」で渡してください。ファイル名で突き合わせます（大文字小文字とフォルダの違いは無視）。

- **JSON と素材を一緒にドロップ**すると、最初から結ばれた状態で画面が出ます
- 素材が見つからないレイヤーは飛ばして復元できます（何が足りないかは一覧に出ます）
- コマが足りないセルや、短くなった音声・動画は、渡した素材の長さにクリップを詰めて組み立てます
- 復元は **元に戻す**（Ctrl+Z）で取り消せます
- JSON はただのテキストなので、あとから中身を読んだり、書き換えたりもできます
- 保存先の決め方は MP4 と同じです（下の「保存先とファイル名」。フォルダを覚えさせていればそこへ書きます）

## 保存先とファイル名

**MP4書き出し** を押すとダイアログが開き、ファイル名と保存先を決められます。

- **Chrome / Edge（PC）** … 「フォルダを選ぶ」で保存先を決めると、次回からもそこへ直接書き出します。同じ名前のファイルがあるときは `名前 (2).mp4` にずらすので、既存のファイルは上書きしません
- **保存ダイアログで場所を選ぶ** … フォルダを覚えさせない場合は、書き出しのたびに保存ダイアログを出せます
- **iPad / iPhone** … 共有シートが開くので「ファイルに保存」から保存先を選びます
- **その他のブラウザ** … ブラウザの既定のダウンロード先に保存されます

### iPad

- Safari を使ってください（ホーム画面追加にも対応）
- 画面が狭いときは上部の **素材** から背景・レイヤーを開きます
- プレビューとタイムラインの間の仕切りをドラッグすると配分を変えられます（ダブルタップで戻す）
- タイムラインはタップで選択、ドラッグで移動 / トリム、ピンチで拡大縮小
- **直接操作** ではステージの絵を指でドラッグ、2本指のピンチで拡大縮小できます
- 分割・コピー・貼り付けなどは再生バーのボタンから操作できます（キーボード不要）
- 透過 PNG は写真アプリより **ファイル** アプリからの読み込みが確実です（アルファが保たれやすいため）
- 書き出し後の **保存 / 共有** で、ファイルアプリや他のアプリへ渡せます

## 開発

```bash
npm install
npm run dev
```

ブラウザで表示された URL を開きます。同じ LAN 上の iPad からアクセスする場合は、Vite が案内する Network の URL を使います。

```bash
npm run build
npm run preview
```

ロジックの確認:

```bash
node --test scripts/test-logic.mjs
```

## 書き出しについて

- 出力はステージの解像度・プロジェクト fps に従います
- ブラウザが H.264 エンコードに対応していれば MP4、そうでなければ MediaRecorder で mp4（だめな環境では webm）になります
- プレビューのミュートがオンのときは、書き出し音声も無音になります
- 市松模様と選択枠はプレビュー専用で、書き出しには入りません
- 撮影処理はプレビューと同じものが焼き込まれます

## 技術

React + Vite。合成と撮影処理は Canvas 2D。音声は Web Audio。書き出しは [Mediabunny](https://mediabunny.dev/)（WebCodecs）と MediaRecorder の併用、保存先の指定は File System Access API です。
